**What I do**

- **AI** - LLM agents, voice and chat bots, and miners for Bittensor subnets that compete on live scores.
- **Data** - pipelines that collect, clean and score data; tracking servers; search over GitHub and email data.
- **Full stack** - TypeScript and Python back ends (Fastify, FastAPI, Postgres, SQLite), web front ends and widgets.
- **New ideas** - I start from the real user's problem, try many ideas cheaply, and keep the ones the numbers support.

**Results**

- 1st place in [ChipForge Quest 1](https://github.com/gold-tree-tech/chipforge-quest1) on Bittensor subnet 108.
- Built [DittoForge](https://github.com/gold-tree-tech/dittoforge), a community board for the SN118 Ditto generator competition.
- Designed [AI Citizen Network](https://github.com/gold-tree-tech/ai-citizen-network), where specialist AI agents hire each other and get paid.
